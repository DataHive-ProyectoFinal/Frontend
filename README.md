Instrucciones para Pagos
*Previamente se tendrá que tener en su carpeta htdocs de xampp la carpeta “Proyecto-DataHive-primeraEntrega” y el mySQL y apache corriendo*
Socio:
Para enviar un pago:
Ingresar al home de socios mediante: http://localhost/Proyecto-DataHive-primeraEntrega/Frontend/Socios/home-frontend-socios.html
Luego de ingresar al home de socios, ir a la sección de “pagos”, allí ingresar los datos que pide el formulario(CI, Monto, Archivo de comprobante, motivo, tipo de pago), y esperar el mensaje de confirmación.

Administrador:
Para verificar un pago: 
Entrara: http://localhost/Proyecto-DataHive-primeraEntrega/Frontend/Backoffice/home-backoffice.html
Ir a la sección de verificar pagos, allí habrá una lista con los datos, presione “Ver” para ver el comprobante de pagos subidos, luego aceptar o rechazar el pago, y a continuación se actualizará el estado del mismo en la BD y desaparecerá de la lista de pagos pendientes.
